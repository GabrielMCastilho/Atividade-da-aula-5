# Atividade-da-aula-5
Possuí o script gerado na atividade da aula 5.
O script explica que seu objetivo é buscar um gene e retornar seu respectivo arquivo Fasta de aminoácidos da proteína traduzida através desse gene, além do número de aminoácidos da proteína.
O script então dá uma lista de genes para consulta e pede para escolher um. Após o usuário escolher, é rodado um loop onde se busca o valor (arquivo fasta) respectivo a chave (gene) dentro de um dicionário criado anteriormente e já incluso no script. O loop então retorna o número de aminoácidos da proteína e a string de como é o arquivo Fasta. Por fim, o loop pergunta se o usuário deseja continuar ou  não sua busca. Se sim, o loop roda novamente, permitindo ao usuário inserir outro gene de interesse. Se não, o script finaliza.
